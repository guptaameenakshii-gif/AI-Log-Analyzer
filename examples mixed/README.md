# Messy Security Log Examples

This folder contains intentionally unstructured test logs for the AI Security Warning Log Analyzer.

Files:
- `auth_300_messy.log` — 300 authentication/login-related entries
- `security_300_messy.log` — 300 mixed network, firewall, privilege, and security events
- `application_300_messy.log` — 300 mixed application/server events

The logs intentionally vary in:
- timestamp formats
- spacing and separators
- log levels
- message structure
- missing fields
- noisy/benign events
- human-readable and machine-style messages

These files are intended to test contextual interpretation rather than strict parsing.
